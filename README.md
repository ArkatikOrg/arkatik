# Arkatik

AI-driven editorial platform publishing verified content on science, medicine, philosophy, and engineering — framed as concrete steps toward a more collaborative, sustainable, and technologically advanced civilization.

## What this is

Arkatik is an open-source project that uses a pipeline of specialized AI agents to find, write, fact-check, translate, and publish science-focused articles. Every article comes with a public **dossier** showing the full process: prompts used, sources consulted, sources discarded, fact-checker output, and any human interventions.

We don’t ask for trust. We give you the tools to verify.

## Philosophy

- Collaboration is presented as a **technical solution to technical problems**, not as a moral virtue.
- The tone is **descriptive and evidence-based** — no sermons, no gurus.
- Predictions always declare a **confidence level** and a **time horizon**.
- Failures and broken promises get the same rigorous coverage as successes.

Read the full [Manifesto](docs/manifesto.md).

## Sections

- **Discoveries** — real scientific news, synthesized and contextualized
- **Vision** — analysis of multi-decade trends and trajectories, anchored to data
- **Bridges** — explicit links between today’s discoveries and tomorrow’s possibilities
- **Frictions** — what didn’t work, why predictions failed, where the construction site got stuck
